# 🌌 Project Overview

**NeuroHome AI** is a futuristic full-stack smart home automation platform designed with ultra-realistic cyberpunk-inspired UI/UX, real-time IoT-style communication, AI interaction, voice automation, and secure authentication systems.

The project simulates a next-generation intelligent living ecosystem where users can monitor and control smart devices through a visually immersive AI dashboard.

This platform combines:

- ⚡ Real-Time Smart Device Synchronization
- 🧠 AI Assistant Interaction
- 🎤 Voice Command Automation
- 🔐 JWT Authentication System
- 🌐 MongoDB Cloud Database
- 📊 Energy Monitoring Dashboard
- 🛰️ Smart Security Simulation
- 🎨 Futuristic Glassmorphism Interface
- 🚀 Full Stack SaaS Architecture
